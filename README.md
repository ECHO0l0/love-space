# 海行 · 私人船员学习空间

szq823.xyz 的船员理论学习应用，替代旧农场首页。旧版仍保存在 Git 历史中。

支持职务/版本/科目筛选，章节/顺序/随机/未学/背题练习，本科目搜索，错题复习、收藏、笔记、隐藏，原卷及自定义限时考试，交卷分析、练习续接、学习统计、深色外观、大字阅读、备份恢复与科目离线缓存。

题库使用 AES-256-GCM 加密，口令通过 PBKDF2-SHA256（600000 次迭代）派生包装密钥，再解锁独立的数据密钥。修改口令无需重写题库数据。仓库仅包含加密题目和图片，口令不进入仓库。解锁密钥只保留在当前浏览器标签会话。用户学习数据存放在 IndexedDB，不自动跨设备同步；导入导出学习备份可迁移数据。本站不连接原题库平台。

所有原题干、标准答案、关联材料、原卷次序和源解析保持来源语义。无题干或无答案的记录不纳入可练题；图片缺失显示提示。不同版本和原卷可有重复题目。图像优先采用原尺寸 WebP；超长图保留源图格式。模拟考试每题等分，成绩用于自测，不代表原平台正式规则。听力与会话不在本站范围。

## 开发与验证

Node.js 22 或以上，无第三方运行依赖。

```sh
npm run dev
npm test
npm run build
```

开发地址：http://127.0.0.1:4173 。Vercel 通过 main 分支自动部署，输出目录 dist。

新增数据必须先在本地规范化并加密，更新 vault 版本路径，不能将访问口令、明文源题库或本机学习备份提交到公开仓库。
